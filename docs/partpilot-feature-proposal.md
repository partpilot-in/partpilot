# Product Proposal: PartPilot Feature Prioritization

## Recommended Roadmap

| Priority | Feature | Recommendation |
|----------|---------|----------------|
| ⭐ Immediate | BOM line notes | Simple to implement and provides valuable user preference data. |
| ⭐ Immediate | Qualification/compliance-aware alternate matching | Extends existing matching logic with high customer value. |
| 🟡 Near-term | Company preference-aware scoring | Highest differentiator; implement in phases starting with configurable profiles. |
| 🟡 Near-term | PCN compliance parsing | Extend existing parser with explicit `unknown` states for safety. |
| 🟡 Near-term | Manufacturer & distributor APIs | Continue expanding structured data integrations. |
| 🟡 Near-term | Datasheet parsing | Focus only on poorly indexed or obsolete parts. |
| 🟠 Prototype | Commodity price exposure | Show price sensitivity indicators instead of forecasts. |
| 🟠 Prototype | Geopolitical sourcing risk | Integrate into alternate ranking instead of a standalone feature. |
| 🔴 Defer | ERP integrations | Build only when driven by customer demand. |
| 🔴 Avoid/Rescope | Z2Data as primary source | High licensing and strategic dependency risk. |
| 🔴 Avoid/Rescope | FAE/contact directory | High maintenance burden and outside core product scope. |
